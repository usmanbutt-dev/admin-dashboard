# Admin Dashboard

A static admin dashboard layout built as a front-end design exercise.

**[View the demo](https://usmanbutt-dev.github.io/admin-dashboard/)**

## What it contains

The page arranges navigation, projects, announcements, event dates, rewards, and statistics in a dashboard layout. It is built with HTML and CSS, using assets in `Assets/` and Font Awesome icons loaded from a third-party script.

## Run locally

Open `index.html` in a browser. Icons require a network connection. There is no build step or backend, and the repository's `script.js` is empty; the dashboard does not load live data.
